# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub Issues.

If you believe you have discovered a security vulnerability in HexSpindle,
please use GitHub's private vulnerability reporting feature for the
HexSpindle repository when available.

Include as much detail as possible, including:

- A description of the vulnerability
- Steps to reproduce the issue
- The affected component or operation
- Potential security impact
- Any suggested mitigation, if known

Please allow reasonable time for investigation and remediation before
public disclosure.
