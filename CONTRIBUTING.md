# Contributing to HexSpindle

Thank you for your interest in contributing to HexSpindle.

HexSpindle is a browser-based data transformation workbench built with
vanilla JavaScript and browser APIs. Contributions to the application,
operations, documentation, tests, and project infrastructure are welcome.

## Before You Start

For significant changes or new features, consider opening an issue first so
the proposed approach can be discussed before substantial work is done.

For security vulnerabilities, do not open a public issue. Please follow the
[Security Policy](SECURITY.md).
