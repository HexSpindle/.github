# HexSpindle Support

Thank you for using HexSpindle.

## Bug Reports

If you believe you have found a bug, please open an issue in the
[HexSpindle source repository](https://github.com/HexSpindle/HexSpindle/issues).

Before opening a new issue, please check whether the problem has already been
reported.

A useful bug report should include:

- A clear description of the problem
- Steps to reproduce it
- Expected behavior
- Actual behavior
- Browser and operating system
- The affected operation or feature
- Example input or recipe when appropriate
- Relevant browser console errors
- Screenshots when they help explain the issue

Please remove sensitive information before posting logs, screenshots, inputs,
or recipes publicly.

## Feature Requests

Feature requests may also be submitted through the
[HexSpindle issue tracker](https://github.com/HexSpindle/HexSpindle/issues).

Please describe:

- The problem or use case
- The behavior you would like
- Why the feature would be useful
- Any relevant examples or references

## Security Issues

Do not report security vulnerabilities through public GitHub Issues.

Please follow the
[HexSpindle Security Policy](https://github.com/HexSpindle/.github/blob/main/SECURITY.md)
and use GitHub's private vulnerability reporting feature.

## Questions and Usage Help

For questions about using HexSpindle, first check:

- The [HexSpindle README](https://github.com/HexSpindle/HexSpindle)
- Existing [GitHub Issues](https://github.com/HexSpindle/HexSpindle/issues)
- The live application at [hexspindle.github.io](https://hexspindle.github.io/)

If the documentation does not answer your question, you may open an issue
with enough context for others to understand what you are trying to
accomplish.

## Scope of Support

HexSpindle is an open-source project maintained on a best-effort basis.

There is no guaranteed response time, service-level agreement, or guarantee
that every feature request will be implemented.

Constructive reports with clear reproduction steps and technical detail are
the easiest to investigate.
